# 全流程自动执行

在新建任务或定时计划中开启「允许全流程自动执行」。默认关闭。开启后，任务草稿、自动派发的后续任务、视频脚本、最终成片和发布文案均自动通过审核；成片合成、配乐和缩略图完成后直接向选定账号排队发布。运营闭环与目标发布账号仍需单独选择。

定时计划详情可以切换后续轮次的策略，只影响之后创建的执行轮次，不改变已有轮次或待审批历史任务。新建时通过顶层 `auto_execute: true` 明确授权，服务端忽略 input_params 中直接注入的开关。接口 `PUT /companies/{company_id}/tasks/{tid}/auto-execute` 使用 `{ "enabled": true }` 修改计划。

自动执行使用任务发起人的企业权限，要求任务执行、审批、视频创建及平台发布权限，在运行、自动审核与发布时重新验证。任务审批保留已通过的审计记录，成片记录自动审核方式和发布内容快照。

自动执行不会绕过预算、数据覆盖不足、素材校验、取消操作、账号失效及发布结果不确定等限制。遇到异常仍会停止并展示错误，不能盲目重复提交。未开启时保留人工审核流程。

测试使用模拟模型和发布接口，不调用付费生成服务或真实发布内容。
