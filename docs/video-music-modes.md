# 默认配乐及静音视频

工作区设置 → 默认视频配乐支持 fixed（固定素材）、random（随机素材）和 none（不使用配乐，静音）。none 不选素材库音频，视频模型请求 audio=false，最终合成移除所有音轨，包括模型返回和复用分镜携带的音频；视频画面、时长和品牌片头保持原有流程。

None 会保存为 default_video_music.selection_mode=none、music_disabled=true，并清空默认 music_asset_id。每个新项目固定保存 music_disabled，数字员工创建项目时继承工作区设置；后续更改默认不会重写已有项目。新建视频也可显式开启“不使用配乐（静音）”。该模式移除全部声音，不保留人声、环境声或原配乐。

固定模式不选择音频，仍表示保留模型音轨，遵守 VIDEO_AUDIO 配置；与 none 的静音语义不同。手动明确指定音乐可以覆盖工作区静音默认。为待审核成片替换音乐属于显式选择新音乐，会关闭该项目的静音设置；本次没有增加对既有成片的一键静音操作。

上线需要先执行增量迁移 20261105_music_disabled，为 video_projects 增加默认 false 的 music_disabled 列，再启动新版本。旧项目不批量修改，旧版本可兼容新增列。备份数据库及当前代码后再部署。

## 任务级配置

新建任务、编辑定时任务的“本任务的视频配乐”支持：跟随工作区设置（workspace）、素材库随机（random）、固定一首（fixed）、不使用配乐/静音（none）、保留模型原声（model）。随机与固定模式可调整音量。固定模式必须选择本企业已处理完成且可用的音频。model 不替换配乐、不强制静音，是否生成音轨仍遵守服务端 VIDEO_AUDIO 配置。

配置保存在 input_params.video_music，优先于工作区默认，并随运营总管→策划→视频制作员的任务派发传递。定时任务每轮复制配置；random 在创建视频项目时抽取一次并保存，重试已有项目不重新抽取。workspace 在创建视频项目时读取工作区最新默认值。修改定时计划只影响后续执行轮次，不改已生成视频或已有执行实例。无可用随机配乐时明确报错，不静默退回模型音乐。

## 大模型超时

HTTP 408/504/524 单独提示中转或上游响应超时，401/403 提示鉴权或权限，429 提示额度/限流，其他 5xx 提示服务异常。未增加自动重试，避免上游已处理但响应超时造成重复调用与计费。视频岗位输入去除重复报告、本地分镜草稿、完整素材目录及历史发布列表，保留已选候选、完整复用合约、上游交付、岗位约束、行业系统指引和企业事实。该精简减少无关上下文，不保证消除中转超时。
