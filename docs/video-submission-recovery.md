# 视频提交不确定恢复

失败的视频详情展示最新的无上游ID提交记录。按分镜选择：
- 关联上游任务：用户确认任务归属，填写任务ID；只查询该任务，读取成功后关联。已被其他分镜绑定的ID拒绝关联。
- 确认重新提交：用户明确接受重复计费风险后，将该次记录标记为允许重试。保留原始错误及确认人、时间、动作审计。

处理全部不确定分镜后，点击原有“重新执行”。已完成分镜复用，已有ID继续轮询，明确失败及人工确认的分镜才重新提交。保存恢复处理本身不会提交生成或自动发布；定时任务不会自动确认不确定提交。

限制：中转查询接口无法证明任务归属，用户必须从中转后台核对，不能仅凭任务可查询就推定归属。无数据库迁移。

验证：28项失败恢复、分镜复用与真实浏览器回归通过；前端构建通过。浏览器验证桌面/390px布局、确认前按钮禁用、任务ID填写、提交确认后记录更新与重复保护。未发起真实付费生成。
