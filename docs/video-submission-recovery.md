# 视频失败后直接重新执行

失败视频详情不再显示中转任务ID输入框或关联步骤。用户点击“重新执行”后：
- 已完成分镜继续复用。
- 已保存中转任务ID且仍在处理的分镜继续查询。
- 未取得中转任务ID的分镜直接重新提交生成；保留原始错误、旧提交记录和重试操作者审计。
- 明确失败的分镜重新生成。重复点击和非企业成员访问仍受保护。

页面提示新请求可能重复计费，无需用户查询中转后台或先逐条确认。只在用户明确点击重新执行时进行重试，不增加无限自动提交。旧关联API保留兼容，前端不再使用。

验证：28项失败重试、分镜复用与真实浏览器回归通过；前端构建通过。浏览器验证没有ID填写入口、手机无横向溢出、一次点击启动恢复并保留旧记录。
