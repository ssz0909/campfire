# 人物开场选材约束

人物开场不是平台默认规则。只在当前任务的目标、原始执行目标、任务标题或任务描述明确提出“人物入镜/出镜/入境开头”“首镜真人”等要求时启用；不读取企业通用岗位说明、员工系统指令或行业模板来触发。明确否定的同一分句不触发。

自动选材使用识别元数据people_visible（兼容旧描述）判断真人，不再依赖“人物”标签恰好出现在任务目标中。合格人物素材获得主题匹配资格；独立保留首位人物候选，优先最近12项目内使用少的，再比较相关性、清晰度及任务哈希轮换。其他场景继续使用现有相关性与分类多样性策略。重复降权不能移除唯一符合要求的人物图片。

候选描述携带required_people_opening，导演上下文携带visual_requirements。质量/成本模式的本地兜底首镜使用真人图片；大模型分镜通过相同校验，任务转视频时再次读取素材识别信息并校验。无合格真人图片或首镜不符时明确报错，不以空景或凭空加人代替；不自动发起额外付费重试。

当前支持的是人物首镜这一明确约束，不是任意自然语言要求的通用语义解析器，也不是成片人物动作检测。图片识别错误需要重新识别；现有成片不会被改写。其他主体、动作、场景的硬约束需要后续各自定义结构化识别字段与校验规则。
