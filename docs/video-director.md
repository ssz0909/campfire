# 视频制作员：15–60秒导演流程

向运营总管或视频制作员明确提出，例如“用酒店泳池、客房和夜景素材制作30秒竖屏短片”。未指定时长默认30秒，支持15–60秒。

1. 从本企业已处理、可用的图片中按主题、清晰度、画幅与场景互补性筛选最多40张候选图，不再固定3张。
2. 视频制作员读取图片识别描述、品牌资料和上游任务，重新选材、排序，交付整体脚本及结构化分镜。分镜包含素材ID、用途、剪辑时长、景别、运镜、画面描述、独立生成提示词和裁切中心。
3. 每镜成片1.5–3.5秒，首镜不超过2秒，总时长必须匹配目标。结构为视觉钩子、体验展开、细节证明、酒店记忆点与行动引导。多素材时相邻镜头不得重复同图；仅一图时必须变化景别并提示素材不足。
4. 脚本审批通过后，根据每镜主体、景别及裁切中心生成统一画幅参考图，逐镜调用视频模型。每条提示词只描述一个连续镜头，要求保持真实酒店结构，不生成字幕、虚构设施或人物。
5. 当前按每镜5秒调用模型，再剪取分镜需要的时长并合成，生成成片及封面供审核。模型计费时长会高于最终成片时长，例如30秒短片通常约12镜，对应约60秒模型生成用量；实际费用由中转服务定价。交付中会显示镜头与生成用量。

LLM导演提示词位于 `backend/app/services/video_director.py` 的 `DIRECTOR_PROMPT`。候选素材不足时仍会存在场景重复，建议补充不同空间、远景、中景及细节图。无模型配置时只提供明确标注的本地规则草稿；字幕、配音、配乐与视觉质量自动评审没有在此流程中实现。

已生成及正在重试的旧项目保留原分镜和模型任务，避免重复提交。请创建新的视频制作任务体验新流程；更新不会自动重新生成或发布旧视频。
