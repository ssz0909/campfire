# 视频制作员：15–60秒导演流程

向运营总管或视频制作员明确提出，例如“用酒店泳池、客房和夜景素材制作30秒竖屏短片”。未指定时长默认30秒，支持15–60秒。

1. 从本企业已处理、可用的图片中按主题、清晰度、画幅与场景互补性筛选最多40张候选图，不再固定3张。
2. 视频制作员读取图片识别描述、品牌资料和上游任务，重新选材、排序，交付整体脚本及结构化分镜。分镜包含素材ID、用途、剪辑时长、景别、运镜、画面描述、独立生成提示词、起止构图、转场类型、转场时长、衔接说明和裁切中心。
3. 每镜成片1.5–3.5秒，首镜不超过2秒，总时长必须匹配目标。结构为视觉钩子、体验展开、细节证明、酒店记忆点与行动引导。整片每张素材只能引用一次，换裁切或运镜也不算新素材；不足时停止并提示补充。30秒至少需要9张不同图片，60秒至少需要18张。
4. 脚本审批通过后，根据每镜主体、景别及裁切中心生成统一画幅参考图，逐镜调用视频模型。每条提示词带入相邻镜头的起止构图和转场意图；模型支持时可直接生成淡入、淡出或匹配动作，不支持时仍保留自然衔接。每条提示词只描述一个连续镜头，要求保持真实酒店结构，不生成字幕、虚构设施或人物。
5. 当前按每镜5秒调用模型，再剪取分镜需要的时长并合成，生成成片及封面供审核。模型计费时长会高于最终成片时长，例如30秒短片通常约12镜，对应约60秒模型生成用量；实际费用由中转服务定价。交付中会显示镜头与生成用量。

LLM导演提示词位于 `backend/app/services/video_director.py` 的 `DIRECTOR_PROMPT`。素材不足时停止制作，建议补充不同空间、远景、中景及细节图。同一场景的不同照片仍可能视觉相似，无重复引用不代表画面内容必然不同。无模型配置时只提供明确标注的本地规则草稿；字幕、配音、配乐与视觉质量自动评审没有在此流程中实现。

已生成及正在重试的旧项目保留原分镜和模型任务，避免重复提交。请创建新的视频制作任务体验新流程；更新不会自动重新生成或发布旧视频。

## 上传背景音乐

素材库及视频项目的配乐选择器支持上传MP3/WAV，完成音轨解析后可试听。新建视频时可选音乐、调整0–100%音量；选择后请求视频模型关闭音频，合成时使用上传的音乐替换原音轨，不足时循环、过长时截取，首尾淡入淡出。默认音量25%。

背景音乐会先跳过开头低于-45dB且持续的静音，重置音频时间戳后再对齐视频；不会删除歌曲中间的停顿。全静音文件会拒绝合成并保留原成片。素材试听仍播放原始上传文件。

在“设置 → 默认视频配乐”中保存企业音乐后，后续数字员工创建的视频项目自动绑定该音乐与音量，生成、审核、发布都使用同一个配乐成片，无需生成后再手动替换。已创建及已发布项目保持原配置；清空音乐保存可关闭默认配乐。单项目显式指定音乐或取消选择优先于企业默认配置。

选择“从素材库随机选取”后，每个新项目仅在创建时从本企业可用、已处理完成的音频中随机选一首并保存，重试和发布不会重新选曲。随机选择可能再次选中同一首；没有可用音频时明确报错，不回退至模型音乐。固定模式清空音乐保存可关闭默认配乐。

数字员工已生成的待审核视频，可以在视频详情的“自选背景音乐”中选择上传音乐并点击“替换成片配乐”。此操作只处理音轨，不调用视频模型，不产生视频模型费用；原成片资产保留，配乐版仍需审核。全部原音轨（包括人声和环境声）都会被替换。已审核及发布的项目不支持修改，避免发布内容和审核记录不一致。
