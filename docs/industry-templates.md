# 行业与视频创作模板

本功能采用通用底座 + 工作区行业 + 管理员维护的行业模板。模板是结构化数据库配置，不执行代码，不决定账号、工具、付费调用或审批权限。

## 使用

1. 平台管理员打开管理后台 → 行业模板。系统初始提供“通用”“酒旅”和原有九个行业选项。原有其他行业先沿用通用规则，管理员可逐步完善，不代表已具备专属业务集成。
2. 编辑定位、内容方向、选材规则、行业用语、禁用表达、选材关键词和文案风格，保存草稿。每条列表规则一行；草稿不改变已发布内容。
3. 预览“通用底座与已保存行业草稿”，点击发布。查看历史版本，可将旧版本复制到草稿并重新发布；不会修改原版本。
4. 新增行业时填写唯一英文标识（如 `restaurant`），创建并发布。无需再改前端选项或重新部署；新开/重新加载的选择页自动读取已发布行业。
5. 企业在“设置 → 企业信息”选择行业；未选择、停用或无法识别的历史行业使用通用模板。已有 `hotel`/`tourism`/酒店/景区别名解析到酒旅，未批量改写企业资料。
6. 新建数字员工任务或视频项目可以覆盖行业。任务详情、视频详情显示实际版本。

## 酒旅模板

住宿与景区共用景观、氛围、周边、打卡和体验表达。客房、入住和住宿服务必须得到企业资料与素材支持，不强制出现。缺少客房图片不等于企业不提供住宿；没有可用周边素材和资料就省略周边，不推测距离、温泉属性或网红热度。

企业名称、设施、地址、实际价格等属于企业资料；片头字体位置、配乐、目标时长、生成模式、素材复用及矩阵账号沿用现有独立配置。默认行动引导为关注、评论或私信咨询；任务明确要求时可覆盖。图片识别依然描述可见事实，不因行业自动认定设施和服务。

## 生效与事实边界

新任务创建时由服务端按任务覆盖 → 工作区行业 → 通用兜底解析，并保存行业版本、内容、通用底座版本和内容校验值。客户端传入的模板快照会被丢弃。系统生成的下游任务、视频项目、重试、复盘及定时计划各轮沿用原快照；管理员修改或停用模板不改变既有任务。要使用新版，请另建任务或定时计划。

模板同时进入本地交付、LLM策划/脚本、选材和视频生成提示词。选材关键词仅在同等主题相关素材间辅助排序，不会压过任务主题或跨租户获取素材。视频模型只接收视觉定位、选材约束和禁用表达，不接收发布文案写作要求。模型输出仍须通过时长、素材归属、重复引用和分镜结构校验。模板约束减少虚构风险，不能替代最终成片与文案核验。

酒店订单连接器保持独立。有酒店连接器或任务明确要求酒店经营/入住分析时继续检查订单覆盖；通用行业内容任务不会仅因没有酒店订单而阻断内容方案。

## 接口与存储

- `GET /api/v1/industries`：已登录用户读取启用且已发布的行业目录，只返回名称、标识、版本与说明。
- `GET/POST /api/v1/admin/industry-templates`：管理员读取全部模板、创建新行业草稿。
- `PUT .../{code}/draft`：保存草稿。
- `POST .../{code}/publish`：发布不可变版本。
- `PATCH .../{code}/status`：启用/停用，通用兜底不能停用。
- `POST .../{code}/versions/{version}/restore`：将历史版本复制到草稿，重新发布后才生效。

写操作携带 `expected_revision`，冲突返回409，需重新加载；仅平台管理员可写。创建、编辑、发布、状态及历史恢复操作记录在审计日志中。数据随数据库一起备份，无额外模板文件或密钥配置。

首次部署需运行 `alembic upgrade head`（迁移 `20261104_industry_templates`），再加载新后端和完整前端；不能仅更新前端。迁移只增加两张表和视频项目快照字段，不重写企业、旧任务或旧视频。回滚应用时建议保留新增表与字段；已创建任务的JSON快照可由旧代码忽略，不需删除配置。

## 验证

后端：`backend/tests/test_industry_templates.py` 覆盖管理员权限、版本隔离、草稿发布、停用兜底、冲突、历史恢复、任务快照、防伪造、项目/下游继承、选材隔离、通用行业执行，以及质量/成本两种模式下实际请求的模板注入。测试不调用收费模型。

前端先 `npm run build`，再用具备 Playwright/Chrome 的 Python 运行 `frontend/tests/industry-templates-ui.py` 与 `frontend/tests/task-matrix-ui.py`，使用模拟业务接口覆盖1440/390宽度下的编辑发布、新行业选择和矩阵账号提交。模型输出质量需用实际业务素材进行后续人工验收，本次自动化测试不生成或发布真实视频。
