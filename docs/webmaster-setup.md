# 营火AI站长工具接入操作指南

管理入口：平台管理员登录 → 管理后台 → GEO运营数据 → 站长工具接入。

所有渠道统一验证 `https://campfire.dawoai.com`，企业的 `/shop/标识` 无需逐个验证。站点地图为 `https://campfire.dawoai.com/sitemap.xml`，动态列出已发布、未下架且企业有效的主页。营火维护地图；向第三方添加站点/提交地图需要管理员在对应站长账号内操作，系统不会假报已提交或已验证。

## 三个渠道的域名验证

| 渠道 | 入口 | HTML标签name |
| --- | --- | --- |
| Google Search Console | https://search.google.com/search-console | google-site-verification |
| Bing Webmaster Tools | https://www.bing.com/webmasters/ | msvalidate.01 |
| 百度搜索资源平台 | https://ziyuan.baidu.com/ | baidu-site-verification |

1. 在渠道网站添加营火HTTPS站点。Google请选择“网址前缀”资源（精确填写 `https://campfire.dawoai.com/`），可使用HTML标签验证；域名资源必须使用DNS验证。
2. 如选择HTML标签：复制对应meta完整标签或content值，到营火该渠道输入框保存。营火将安全的验证meta直接输出在官网首页head，无需前端JavaScript。可查看首页源代码核对。
3. 返回渠道网站点击验证。营火的“HTML标签已配置”仅表示本地已保存，不等于第三方验证通过。请保留标签以便后续复验。
4. 如选择DNS验证：在域名DNS管理处按渠道给出的类型、主机记录和值添加TXT记录。以渠道页面要求为准，不要根据示例猜记录值；营火后台无需填写HTML标签。
5. 在渠道的站点地图功能提交统一sitemap地址。百度若当前账号未提供地图提交入口，使用实际开放的提交能力并等待抓取，不能当作已成功提交。提交成功也不保证收录。

## Google搜索表现API同步

1. 在Google Cloud项目启用 **Google Search Console API**。
2. 创建服务账号、生成并下载JSON密钥。无需把密钥发到聊天中。
3. 在Search Console对应资源“设置 → 用户和权限”添加服务账号邮箱，授予能够读取搜索表现的权限。服务账号不是网站域名所有权验证的替代方式。
4. 在营火展开“配置Google搜索表现自动同步”，选择实际授权资源。支持营火网址前缀或 `sc-domain:campfire.dawoai.com`；不接受其他域名。
5. 粘贴JSON并保存。密钥在数据库加密保存，界面仅返回保存状态及服务账号邮箱。留空保留旧密钥，可勾选清除。
6. 点击同步，或开启每天自动同步。任务存储后由独立API采集线程串行执行，通常30秒内开始。同步队列不启动浏览器，不占用发布/视频任务执行器。服务端需启用现有 `EXECUTION_AUTOMATION_ENABLED`（生产已启用）。

同步最近30个数据日，预留3天延迟，维度为日期/页面，类型web、final。Google搜索分析日期采用提供方口径（通常太平洋时间），不把它当作营火访问事件的上海时区数据。每次最多读取10000条并检查是否还有下一页；超过上限、接口错误、权限错误均不写本次结果，保留先前数据。即使未达到上限，Google也可能只提供主要记录，不宣称全量。

自动任务每天尝试一次，失败在界面展示原因，可手动重试；重复请求在排队/运行时合并。进程重启后排队任务保留，运行中断超过15分钟可恢复。自动模式关闭会停止新增定时采集，不取消已经排队的任务；清除凭据后不再发出授权请求。

HTTP 403通常需要检查API是否启用、资源标识是否正确、服务账号是否加入该资源。令牌错误通常需检查密钥与服务账号状态。服务器也需要能够访问Google官方API。错误详情不存储密钥或上游完整响应。

## 百度、Bing报表导入（Google也支持）

当前版本没有提供百度/Bing的自动统计API连接器；接入能力为验证标签、提交指引、带来源的报表导入和企业归属统计。百度普通URL推送令牌不是搜索表现读取凭据。

1. 从实际站长工具导出真实搜索表现，将数据整理为页面/日期汇总；跨设备或关键词的行先正确聚合，不能把总表与明细重复叠加。
2. 下载营火CSV列名模板，填入 `day,page,clicks,impressions,position`。`position`可空，日期必须为 `YYYY-MM-DD`，点击和曝光为非负整数；页面可使用营火完整HTTPS网址或 `/shop/标识` 相对地址。
3. **缺少日期或页面维度的聚合报表不能直接导入**。不允许把一个周期总数分摊为每日数据，不能凭估计补零。若提供方无法提供此维度，请保留原始报表，等待相应适配。
4. 文件使用UTF-8 CSV，最多2MB/10000行，日期在近730天内。填写报表来源说明并确认真实来源后导入。
5. 同一渠道、页面、日期覆盖旧值，不累加；同文件重复键会拒绝整批。全部校验通过才写入。Google API也会更新对应日期窗口内的API数据；手工导入与API同键以最近写入为准。

## 查看效果与数据口径

- 企业：GEO页面或仪表盘的“GEO与主页表现”中查看各渠道曝光、点击、点击率和有依据的平均排名。
- 管理员：GEO运营数据查看平台各渠道合计；“查看明细”展示对应企业的数据。新导入后刷新统计。
- 企业归属使用准确域名和 `/shop/标识`，历史更名路径仍归原企业；不使用企业名称模糊匹配。其他页面及未匹配路径仅进入管理员平台合计，导入结果单独报告匹配与其他条数。
- 数据按渠道分别统计，保留来源和截至日期；手工导入的来源由管理员提供，不代表平台独立核验。某渠道无数据不当作零曝光、未收录或未被推荐。
- 搜索曝光/点击不等于已收录页面数，不等于实际咨询，更不等于联网大模型推荐。联网模型引用监测仍需另行接入。
