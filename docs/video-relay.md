# 视频中转与员工协作

后端从 backend/.env 读取 LLM_BASE_URL / LLM_MODEL / LLM_API_KEY，以及 VIDEO_BASE_URL / VIDEO_MODEL / VIDEO_API_KEY。两组密钥独立，不相互复制。

## TokenSpace 请求

POST 地址支持填写 /v1 根地址或完整 /video/generations。请求由 model、prompt、metadata 组成。metadata.parameters 包含 resolution、duration、audio，首帧图片通过 metadata.input.media 中的 first_frame 提交。当前接口适配只传 1 张图片，不宣称支持多张参考图。分辨率和音频默认分别为 VIDEO_RESOLUTION=720P 和 VIDEO_AUDIO=true。比例及风格写入提示词。

## 图片素材识别与选片

图片上传提取尺寸和缩略图后，后台把缩小后的图片以 OpenAI 兼容 `image_url` 多模态格式提交至 LLM_BASE_URL。模型返回类别、中文标签、画面描述和人物可见性，保存到 assets.category/tags/source_description 与 metadata.vision_analysis。识别失败不影响原图使用，可手动修改或重试；图片识别需要中转模型支持视觉输入。模型用量记录在识别元数据中。当前不会据图片推断设施承诺、价格、酒店事实或版权。

视频岗位草稿阶段，在同企业、可用、已识别或人工标注的图片中依据主题、标签和类别确定性排序，选择最多 3 张，在脚本草稿中列出素材 ID 和镜头顺序；审批后把同一组素材绑定到视频项目。操作者可在素材页搜索/筛选并修订标签，后台识别不会覆盖人工标注。独立视频项目支持最多 5 张并保持选择顺序。

单图作为 first_frame 调用配置的视频模型。多图用本机 FFmpeg 按选定顺序缩放裁切并硬切拼成竖屏短片，不调用视频模型，也不会产生视频模型用量；需在部署主机安装 ffmpeg。当前多图模式不添加旁白、字幕、音乐、转场动画。成片均进入人工预览和审核。

默认查询 GET {生成地址}/{task_id}；VIDEO_STATUS_URL 可覆盖完整模板，保留 {task_id} 占位符。对不存在任务的只读查询返回 400 task_not_exist，证明该路由可达；尚未执行付费生成验证。

## 任务协作

员工在已配置 LLM 时读取本企业上下文，输出结构化草稿和后续行动。完全未配置时明确使用规则草稿；只配置一部分时报错，不伪装为模型产出。

审批运营总管草稿后自动创建策划、分析任务；策划审批后派发视频脚本任务；视频脚本审批会创建视频项目并启动付费生成。各阶段继续保留人工审批，不自动发布。允许的岗位转换是有限无环图，重复审批或派发不会重复创建同一直接下游岗位任务。不同分支可能各自生成独立策划任务。

视频完成后下载入企业素材库，使用 ffprobe 验证视频流、时长、尺寸，FFmpeg 生成缩略图，进入待审核。首帧模式只接受本企业可用图片。本地存储必须配置模型服务可访问的 PUBLIC_BASE_URL；参考视频风格分析尚未实现。

## 恢复与边界

数据库保存服务商任务 ID。重启后只恢复已知任务的查询和下载，不自动重提没有确认 ID 的请求。进程内去重加 PostgreSQL advisory lock 防止多个进程同时执行同一项目。外部提交与本地写入不具备跨系统原子性，提交结果不确定时需要核对服务商后台。

Web 发布从审核通过的视频项目解析本机文件，检测成功提示后才标记已发布；未确认的结果要求人工核对。作品 ID 提取、图文发布、平台页面适配仍需真实账号验证。

数据同步读取已登录数据中心页面中明确且唯一的账号级指标，不猜测数值、不冒充单作品归因。指标变化后创建分析任务；审批其建议可继续派给策划。仍需用户点击同步，不支持无人值守周期采集。
