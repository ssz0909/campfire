# 人物素材动态规则（2026-11-17）

质量优先、成本优先、无LLM兜底分镜及素材库手动再生成统一追加人物动作指引。导演根据原图姿态与实际场景设计一个清晰动作，区分摄影机运动与人物主动动作；在前0.3秒启动，并在成片实际保留秒数内展示动作变化。动作可为转头回眸、手部互动、迈步或姿态变化，按画面条件选择，不强制每个人都挥手，不新增人物/道具，不让雕塑或海报人物动起来。保持身份、服装、解剖结构与空间稳定。

候选素材向导演传递视觉识别people_visible字段；实际模型请求也追加动作要求，覆盖旧脚本只有轻拉远的问题。明确有人物的分镜增加human-action-v1兼容标记，旧静态人物分镜不会被新动作项目自动复用。纯环境素材仍使用原运镜逻辑，无人物时不能新增人。

这是提示词及复用约束升级，不是生成结果的动作检测。模型是否遵循仍需预览审核；没有增加付费自动重试。已有成片不改写；已提交的上游任务继续沿用原请求，避免重复计费。需要新动作效果时创建新任务，或在素材库使用再次生成分镜。
