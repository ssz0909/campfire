# 分镜素材入库与复用

新建视频项目、数字员工任务可以设置“分镜素材使用策略”，与质量优先/成本优先独立：

- 优先复用：匹配本企业已审核的原始分镜，不足部分提交视频模型。
- 全部重新生成：维持原有生成策略。
- 仅用已有分镜：生成前检查完整分镜计划，缺少匹配库存就停止，不补调视频模型。数字员工的文本规划仍可能调用文本大模型。

模型原始片段在整片拼接、配乐和品牌字样之前入库。素材库筛选视频或搜索“AI分镜”可查看、播放，显示审核状态与复用次数。只有最终成片审核通过且实际采用的片段可以跨项目复用；企业之间隔离，已删除或停用素材不参与匹配。

首版采取保守匹配：参考图、画幅、生成模式、景别、裁切中心、运镜、风格、分镜描述和生成要求一致，片段时长充足。成本模式还检查段内分镜。带相邻转场要求的片段暂不跨项目复用，避免将淡入淡出放错位置。相同分类不代表可替代，同一成片不重复使用同一库存片段。匹配优先采用使用次数较少的库存。

复用之后仍重新拼接并应用当前项目配乐和品牌设置。详情页质量检查结果记录复用数及模型片段数。复用次数按引用项目计数，失败重试不会重复累加，不代表发布次数。已有模型提交记录优先恢复原任务，不因新增库存替换未知付费提交。

此版本上线后生成的原始分镜自动保存。历史成片不会自动拆解为原始分镜，历史临时下载链接也不会被批量重新下载。已有项目迁移后保留“全部重新生成”，新建页面默认“优先复用”。
