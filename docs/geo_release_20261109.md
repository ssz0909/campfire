# GEO、主页统计与官网首期交付

本次交付对应 GEO P0 基础版及轻量站内检索，不表示规格书 P1/P2 全部完成。

已实现：

- 企业GEO导航、独立公开资料、通用及酒旅主页模板、品牌色、模块排序和显隐、企业确认事实及来源/有效期、公开封面。
- 草稿预览、发布快照、版本历史、撤回、模板快照；首次公开网址锁定，管理员特殊更名有审计，旧地址301直达当前地址且不能重新分配。
- 无需JavaScript读取的企业/服务/问答HTML、canonical、Organization结构化数据、robots与站点地图。
- 官网产品说明、企业站内搜索及地区/行业筛选、分页；按已发布公开资料检索，无结果不编造推荐。搜索结果不表示外部模型推荐。
- 公开信息纠错反馈、管理员处理说明及审计。额外确认事实已过期时阻止新发布，现有页面过期值停止当作当前承诺展示。
- 发布结构检查、现有调度器每日结构复检；不使用浏览器、不自动发布企业资料。
- 浏览器浏览、每日匿名访客估算、联系信息展开、可见站内结果展示及点击；事件去重、逐日汇总、签名统计凭据、来源分类、疑似机器人及自测排除。
- 企业仪表盘与GEO明细；管理员企业分页统计、官网与企业浏览分开、模板维护及反馈处理。

边界与后续阶段：

- 主浏览口径为浏览器成功上报；关闭JS、拦截上报和来源缺失会影响统计。UA只能标识疑似机器人，不证明官方爬虫身份。公共统计为估算，签名和限流不能彻底防止刷量。
- 原始事件和匿名访客标识保留90天，日汇总保留730天，由每日调度及事件清理执行。界面当前提供7/30/90天。
- 当前只实现快照结构检查，尚无外网可达性探测、证据审核认证、自动纠错、AI内容任务、版本一键恢复、文章、多经营地点、导出等增强。
- 站长工具曝光/收录、联网模型回答引用、实际咨询尚未接入，明确显示未接入。不会将站内试搜或联系点击充当外部曝光或实际咨询。
- 搜索首期在现有数据库存储公开快照，按最多2000企业的有界候选集执行关键词/可选向量排序，超过容量返回维护提示；扩容时替换为数据库索引/pgvector。未使用Elasticsearch。
- 语义索引使用可选 EMBEDDING_BASE_URL / EMBEDDING_MODEL / EMBEDDING_API_KEY；GEO_SEMANTIC_SEARCH_ENABLED=true 开启查询向量调用，默认关闭以控制公开搜索成本。配置异常自动回退关键词，不影响公开主页。
- 所有私有订单、成本、平台登录状态和未明确选择的素材不会进入公开检索。上线不会自动发布任何现有企业。

验证：后端重点回归与隔离数据库Playwright整体验证117项通过；Vue类型检查和生产构建通过。隔离验收覆盖保存、预览、发布、刷新、检索、移动端与管理员界面；未在生产发布虚构企业。

部署采用新release目录及软链接切换，切换前保存旧代码、数据库dump、Nginx与受保护环境配置。数据库变更仅新增GEO表；回退恢复旧应用与Nginx但保留新增表，避免删除上线后产生的资料。执行前先在独立数据库演练升级、降级及再次升级。

## 动态 llms.txt 补充

- `/llms.txt`：平台说明、来源边界、重要公开页面和前100家公开企业的名称/摘要/规范网址。
- `/llms/companies/{page}.txt`：按规范标识稳定排序的目录，每页100家，前后页导航覆盖全部公开企业；不将全部企业资料一次加载到内存。
- `/shop/{slug}/llms.txt`：企业当前公开资料的纯文本Markdown版本，包含介绍、显示中的服务/问答、确认且未过期的事实值及公开联系信息。过期事实值显示待更新。
- 每次请求读取已发布快照，无需人工维护文件或调用模型。保存草稿不改变内容；更新发布立即更新；撤回、下架、企业停用或删除后停止列出及访问；管理员更名后目录使用新网址，旧企业文本入口301直达新网址。
- 返回UTF-8 `text/plain`、`no-store`、`nosniff`，支持GET/HEAD；Nginx为根文件与分页目录单独代理，避免落入SPA。公开HTML提供内容导航发现链接。
- 不读取内部企业介绍、凭证或草稿，不导出隐藏模块及未确认事实；企业名称/文本压平换行并转义Markdown/HTML，避免破坏导航结构。公共目录只保留短摘要，全文以企业入口为准。
- 不实现 `llms-full.txt` 全站无界拼接；分页链接为营火扩展，不能假定所有工具会自动遍历。llms.txt仅提供导航，不等于通知模型、收录证明或推荐承诺。
- 验证覆盖完整发布生命周期、别名、停用/删除、公开隔离、Markdown转义、过期事实与101家企业分页。无需数据库迁移或前端重建。
