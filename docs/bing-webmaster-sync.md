# Bing搜索表现自动同步

## 配置与使用

管理员进入「GEO运营数据 → 站长工具接入 → Bing Webmaster Tools」，展开「配置Bing搜索表现自动同步」。

1. 在Bing Webmaster Tools完成营火站点验证，使用有该站点权限的账号在API访问入口生成API Key。
2. 选择与Bing后台一致的营火HTTPS站点地址，填写API Key并保存。留空保留旧密钥；清除凭据可删除已保存密钥。
3. 点击「同步Bing Webmaster Tools搜索表现」加入独立采集队列；也可开启每天自动同步。
4. 查看同步状态、最近写入条数、企业匹配条数及数据说明。企业端与平台管理端沿用现有外部搜索统计。

不要在聊天或Git仓库中提供真实密钥。密钥按现有平台加密机制保存，不通过配置接口回显，不写入审计详情；HTTP请求日志对密钥脱敏。

## 数据与执行范围

- 使用官方固定端点 https://ssl.bing.com/webmaster/api.svc/json/GetPageStats ，API Key认证，禁止重定向，不访问管理员提供的任意地址。
- 该方法返回热门页面，官方文档说明按周更新；仅保留接口返回日期在最近30天内的数据，不请求或伪造逐日明细，不代表全部页面或全量搜索。界面明确显示此限制。
- 按已登记企业公开主页路径归属数据，其他本站页面只进入平台合计；跨域、非HTTPS记录不采集。
- 日期支持官方JSON的/Date(milliseconds±offset)/及ISO格式；重复页面/日期拒绝写入，避免重复统计。最多10000条，超限失败并建议报表导入。
- 每天调度最多一次自动尝试，立即同步可手动重试；Google和Bing状态独立，复用全局串行API采集器，不启动浏览器，不占用视频发布队列。
- 完整解析成功后，事务替换对应期间原API记录；失败保留旧结果。不删除不同日期/页面的手工报表。同一渠道/日期/页面只有一个存储值，API与手工导入相遇时后写覆盖，不叠加。
- API访问失败、数据为空及凭据未配置不等于网站未收录。同步搜索表现不等于大模型引用监测。
- 无数据库迁移；保留Google API同步、三个渠道验证和报表导入。

## 验证

前端构建通过；31项站长工具、GEO及真实浏览器回归通过。覆盖凭据权限与不回显、日期时区、错误结构、跨域过滤、幂等、失败保留、企业归属、每日调度和两个渠道隔离。测试使用隔离数据库及模拟API，未使用真实Bing账号凭据。
