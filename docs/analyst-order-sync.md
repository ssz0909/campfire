# 数据分析员按任务补同步订单

数据分析员执行任务时，先解析 `input_params.date_from/date_to`（YYYY-MM-DD），
未提供时识别目标中的本年度、今年、去年、指定年份、指定年月、本月、上月、近 N 天或完整起止日期。
本年度以 Asia/Shanghai 当天为截止日；未指定时间时默认近 30 天。
不能明确解析的季度、同比和环比要求用户指定范围，不静默改成近 30 天。

分析前使用本企业 `hotel_sync_jobs` 的成功记录计算缺失范围，按月补同步；
partial/failed 记录不能视为完整覆盖，今日数据会重新拉取。
每次同步生成 trigger=agent 的同步记录，任务日志记载起止日期。
只有拥有连接器配置权限的任务发起人可以触发自动同步，员工仍须具备企业数据权限。
已有同步任务运行时不启动另一轮同步；任务取消后不再启动后续月份。

Web 连接器使用平台日期过滤条件，历史数据可用性由平台实际响应决定；
开放 API 保留现有最近 90 天限制，不通过切分请求绕过历史访问限制。
登录过期、字段变化、部分失败或权限不足时，报告标记覆盖不足，只分析已同步样本。

统计日期是订单创建日期，不能解释为入住日期、营业日收入或财务实收。
历史成功同步只是覆盖记录，不保证历史订单之后未变化；需要更新历史订单时可手动重同步。
年度同步可能耗时较长；当前 inline 模式仍在任务请求内等待，生产长任务应使用已有 Celery 执行模式。

验证：日期解析、成功覆盖合并、缺失月份、部分失败、权限不足、API 历史限制、
工作流调用和任务交接范围继承均有测试。未自动调用真实生产连接器补全年数据或付费模型。
